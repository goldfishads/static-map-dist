# static-map

Release output of the Goldfish proposal map: one script and public-domain
boundary data, served to proposal pages through jsdelivr. Nothing here is
hand-edited; the goldfish-map release workflow pushes each version as a tag.

```html
<script src="https://cdn.jsdelivr.net/gh/goldfishads/static-map-dist@v0.1.0/dist/static-map.js"
        integrity="sha384-5iBRAyR91IPWIK/j138ldjTzEvLXmIbt6lEU62bE7t14FRgjd7rzZj2lp+q1UiLH" crossorigin="anonymous"></script>
```

Data: US Census Bureau cartographic boundaries and urban areas, Natural Earth
roads and populated places. All public domain; see LICENSE-DATA.md.
