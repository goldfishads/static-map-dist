# static-map

Release output of the Goldfish proposal map: one script and public-domain
boundary data, served to proposal pages through jsdelivr. Nothing here is
hand-edited; the goldfish-map release workflow pushes each version as a tag.

```html
<script src="https://cdn.jsdelivr.net/gh/goldfishads/static-map-dist@v0.2.0/dist/static-map.js"
        integrity="sha384-CIQVFFbLvq+rLhwZ4zJp+0GbG39vzEaSzbRBYPgIpTKIk4sOhN3D/a9nccyXzx3J" crossorigin="anonymous"></script>
```

Data: Natural Earth countries, lakes, state and province lines, roads and
populated places; US Census Bureau cartographic boundaries and urban areas. All public domain; see LICENSE-DATA.md.
